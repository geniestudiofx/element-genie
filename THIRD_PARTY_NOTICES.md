# Third-party software

Element Genie is built on these open-source projects. Each keeps its own licence.

| Project | Used for | Licence |
|---|---|---|
| [Dear ImGui](https://github.com/ocornut/imgui) (docking branch) | Scene Setup interface | MIT |
| [ImGuizmo](https://github.com/CedricGuillemet/ImGuizmo) | Move / rotate / scale gizmo | MIT |
| [GLFW](https://github.com/glfw/glfw) | Scene Setup window | zlib |
| [glad](https://github.com/Dav1dde/glad) | OpenGL loader (generated, in `ext/glad`) | MIT / Public domain |
| [GLM](https://github.com/g-truc/glm) | 3D maths | MIT |
| [stb](https://github.com/nothings/stb) | Image loading, font rasterising | MIT / Public domain |
| [NanoSVG](https://github.com/memononen/nanosvg) | SVG logo import | zlib |
| [earcut.hpp](https://github.com/mapbox/earcut.hpp) | Polygon triangulation | ISC |
| [ufbx](https://github.com/ufbx/ufbx) | FBX / OBJ import | MIT / Public domain |
| [cgltf](https://github.com/jkuhlmann/cgltf) | glTF / GLB import | MIT |
| [nlohmann/json](https://github.com/nlohmann/json) | Scene files | MIT |
| [Inter](https://rsms.me/inter/) | Interface and 3D text font (embedded in `src/fonts.cpp`) | SIL Open Font License 1.1 |

**Adobe After Effects SDK** — needed to build the plug-in. It is not included in this repository and is not open source; download it free from Adobe.
